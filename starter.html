Shapes

Pictures & movies

Load pictures or movies, select a shape and pick one under fill, or drop a file straight onto a shape. Movies loop and follow play / pause / restart / speed. Files are kept in this browser between reloads.

Reference image

Shoot the object from the projector's position, load it here, and trace over it.

Output

The map is pinned to the physical screen: a window shows the part of it underneath, and fullscreen (F11 or F) reveals the rest without moving anything.

Two screens

Set Windows to Extend (Win+P), then stretch this window over both screens: un-maximize it and drag its edges, or use open spanning window. The map is pinned to the output screen; this panel and the preview stay on the other. Edit in the preview or right on the projector. F puts the page fullscreen on the output screen only, as browsers can't go fullscreen across two screens. Tip: in Windows display settings, put the projector below or lower than the laptop screen so the browser's title bar stays off it.

Project

Autosaves to this browser. Ctrl+Z / Ctrl+Shift+Z to undo. Imports setups and maps exported from here or from the full Ultraviolet app.

Setups

A setup is the whole page: shapes, fills, reference photo, aspect, and the two-screen settings. Saving under an existing name replaces it. Setups stay in this browser; export one to move it.
